# CRLM CAF/ECM Stromal Integrated UMAP Request

Date: 2026-07-09

## Purpose

Generate one shared stromal-supported UMAP for `GSE178318` and `GSE245552`, instead of plotting the two separately computed UMAP embeddings side by side.

This corrects the current Figure 1 and Figure 2 draft limitation: those drafts used per-dataset UMAP coordinates exported from two independently processed Seurat objects. A pan-atlas-style figure should use a single shared embedding after integration.

## Inputs

Use the existing PC-local clustering object directory:

`bioinformatics-reproduction/projects/crlm-caf-ecm-spatial-niche/desktop_exchange/requests/20260708_core_geo_download/derived_stromal_subset_clustering_20260708/`

Expected PC-local RDS files:

- `gse178318_stromal_subset_seurat_res0.4.rds`
- `gse245552_stromal_subset_seurat_res0.4.rds`

These objects were generated by `20260708_stromal_subset_clustering`.

Each object must contain these metadata fields:

- `dataset_id`
- `main_cluster`
- `review_class`
- `sample_label`
- `tissue_site`
- `top_marker_program`
- `score_margin`

If a required metadata field is absent, stop with an explicit error.

## Command

Run from the repository root:

```bash
Rscript bioinformatics-reproduction/projects/crlm-caf-ecm-spatial-niche/desktop_exchange/requests/20260709_stromal_integrated_umap/scripts/pc_stromal_integrated_umap.R
```

The script uses:

- `Seurat`
- `data.table`
- `ggplot2`
- `patchwork`

The script can install missing CRAN packages on the PC if needed.

## Analysis Scope

1. Read the two PC-local stromal subset Seurat objects.
2. Preserve source metadata:
   - `dataset_id`
   - `main_cluster` as `source_main_cluster`
   - `review_class`
   - `sample_label`
   - `tissue_site`
   - `top_marker_program`
   - `score_margin`
3. Normalize each object and select variable features.
4. Run Seurat anchor-based integration across `GSE178318` and `GSE245552`.
5. Run PCA and UMAP on the integrated assay.
6. Run graph clustering on the integrated embedding at resolutions `0.2`, `0.4`, and `0.6`; use resolution `0.4` as `integrated_cluster`.
7. Export per-cell integrated UMAP coordinates and small composition tables.
8. Save the integrated Seurat object only in a PC-local derived directory; do not commit it.

## Interpretation Boundary

This request creates a shared visualization and review embedding. It does not finalize cell labels, does not remove carryover groups, and does not override the previous cluster-level evidence table. Final figure labels should still be based on marker evidence, source composition, and carryover review.
