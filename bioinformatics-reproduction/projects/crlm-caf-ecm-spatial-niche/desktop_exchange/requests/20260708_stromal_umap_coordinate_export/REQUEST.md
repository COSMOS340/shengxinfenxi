# CRLM CAF/ECM Stromal UMAP Coordinate Export Request

Date: 2026-07-08

## Purpose

Export the per-cell UMAP coordinates and metadata from the PC-local stromal subset Seurat objects generated by `20260708_stromal_subset_clustering`.

This is needed to redraw a publication-style CRLM CAF/ECM atlas figure that follows the same logic as the pan-cancer macrophage atlas figure: data overview, atlas landscape, marker evidence, and tissue or spatial distribution.

Do not upload the Seurat RDS objects or dense count matrices.

## Inputs

Use the existing PC-local clustering object directory:

`bioinformatics-reproduction/projects/crlm-caf-ecm-spatial-niche/desktop_exchange/requests/20260708_core_geo_download/derived_stromal_subset_clustering_20260708/`

Expected PC-local RDS files:

- `gse178318_stromal_subset_seurat_res0.4.rds`
- `gse245552_stromal_subset_seurat_res0.4.rds`

The Seurat objects are expected to contain a `umap` reduction and these metadata fields:

- `dataset_id`
- `main_cluster`
- `review_class`
- `sample_label`
- `tissue_site`
- `top_marker_program`
- `score_margin`

If a required field or the `umap` reduction is missing, stop with an explicit error.

## Command

Run from the repository root:

```bash
Rscript bioinformatics-reproduction/projects/crlm-caf-ecm-spatial-niche/desktop_exchange/requests/20260708_stromal_umap_coordinate_export/scripts/pc_export_stromal_umap_coordinates.R
```

The script uses:

- `Seurat`
- `data.table`
- `ggplot2`

The script can install missing CRAN packages on the PC if needed.

## Expected GitHub Upload Directory

Upload only small tables, PNG previews, and status files to:

## Interpretation Boundary

This request only exports coordinates and metadata from previously generated review objects. It does not rerun clustering, does not change cluster identities, and does not finalize biological labels.
