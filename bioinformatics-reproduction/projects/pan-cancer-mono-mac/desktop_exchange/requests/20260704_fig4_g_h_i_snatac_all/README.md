## Run

From the repository root on PC:

```powershell
cd I:\shengxinfenxi\bioinformatics-reproduction\projects\pan-cancer-mono-mac
powershell -ExecutionPolicy Bypass -File desktop_exchange\requests\20260704_fig4_g_h_i_snatac_all\scripts\run_fig4_g_h_i_snatac_all.ps1
```

The script sets:

```text
FIG4_RUN_SCOPE=all
FIG4_SAVE_RDS=false
FIG4_REFERENCE_LABEL_COLUMN=fig4_display_label
FIG4_OUTPUT_DIR=fig4_snatac\outputs_fig4g_hi_all
```

The R script will use `FIG4_GEO_DIR=fig4_snatac\raw\GSE306459`. If the 15 H5 files and 15 `fragments.tsv.gz` files are already extracted there, it should reuse them. If any needed file is absent, the current R script falls back to `GSE306459_RAW.tar`; prefer reusing the files extracted during the previous PC run or using `scripts/extract_tar_members_http_range.py` manually to avoid repeating a full 87.55 GB archive download.

Do not upload R packages, the raw GEO archive, H5 files, or fragment files into GitHub.
